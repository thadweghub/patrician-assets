Editable index for the photos in this repo. This is the file the website builder (Fable / Claude) reads to pick photos by room.
Repo: https://github.com/thadweghub/patrician-assets — public. Direct URL pattern: `https://cdn.jsdelivr.net/gh/thadweghub/patrician-assets@main/<folder>/<file>`

## How to add a photo
1. Upload the file into the folder for its room (zen-garden, rose-bowl-hide-away, route-66, pashas-paradise) or shared area (exterior, terrace-views, breakfast, other, videos/drone).
2. Add one row to the table below: file, room, what it shows, and whether to use it on the website.
3. Videos: GitHub web upload caps at 25 MB per file. Drone videos over 25 MB go to YouTube (unlisted) instead — put the YouTube link in the Videos table below, not the file here.
